# Connecter votre Compte WhatsApp

Pour envoyer des messages via CONVESSA, vous devez connecter votre numéro WhatsApp personnel ou professionnel à votre compte. Ce numéro devient l'expéditeur de tous vos messages.

---

## Étapes de connexion

1. Depuis votre tableau de bord CONVESSA, cliquez sur **Sessions** dans le menu latéral
2. Cliquez sur le bouton **Connecter un numéro**
3. Un **QR Code unique** s'affiche à l'écran (valable 60 secondes)
4. Ouvrez WhatsApp sur votre téléphone et accédez aux **Appareils liés**
5. Scannez le QR code affiché

**Sur Android** : Menu (3 points) > Appareils liés > Lier un appareil  
**Sur iPhone** : Réglages > Appareils liés > Lier un appareil

---

## Après la connexion

Une fois le QR code scanné, votre compte est connecté et votre clé API devient disponible dans l'onglet Sessions. Vous pouvez alors commencer à envoyer des messages via l'API.

---

## Reconnecter

Si votre connexion est interrompue, retournez dans l'onglet **Sessions**, cliquez sur **Reconnecter** et scannez à nouveau le QR code. Votre clé API reste inchangée.

---

## Bonnes pratiques

- Maintenez votre smartphone connecté à internet (Wi-Fi ou 4G/5G)
- Sur Android, désactivez l'optimisation de la batterie pour WhatsApp
- Gérez toujours la connexion depuis votre tableau de bord CONVESSA
