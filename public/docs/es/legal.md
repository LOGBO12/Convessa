# Condiciones de uso

*Última actualización: julio de 2026*

## 1. Objeto

Estas condiciones rigen el uso de la API de Convessa, que permite el envío de mensajes de WhatsApp a través de una sesión que conectas escaneando un código QR.

## 2. Ausencia de afiliación

Convessa utiliza una biblioteca no oficial (Baileys) que se conecta a WhatsApp de la misma manera que un cliente de WhatsApp Web. Esta plataforma no está proporcionada, aprobada ni afiliada a WhatsApp Inc. ni a Meta Platforms, Inc.

## 3. Riesgo de bloqueo

WhatsApp prohíbe el uso de clientes no oficiales en sus Condiciones de uso. El número conectado puede ser bloqueado temporal o permanentemente, en particular en caso de envío masivo, mensajes no solicitados o comportamiento considerado automatizado y abusivo.

Ni la plataforma ni sus operadores pueden ser considerados responsables de un bloqueo de tu número.

## 4. Cuenta y clave API

Una sesión de WhatsApp corresponde a una cuenta de usuario y a una clave API única. Eres el único responsable de la confidencialidad de tu clave. En caso de sospecha de compromiso, desconecta tu sesión inmediatamente desde el panel de control.

## 5. Usos autorizados

Te comprometes a:

- Enviar mensajes únicamente a destinatarios que hayan consentido explícitamente ser contactados
- Mantener un volumen de envío razonable
- Cumplir con el RGPD o cualquier normativa aplicable sobre protección de datos personales

## 6. Usos prohibidos

Está formalmente prohibido utilizar este servicio para:

- El envío masivo no solicitado (spam)
- El phishing, el fraude o la usurpación de identidad
- Cualquier contenido ilegal
- El acoso o la intimidación
- La violación de los derechos de un tercero

Cualquier infracción conlleva la suspensión inmediata de la sesión y de la clave API.

## 7. Disponibilidad

El servicio se ofrece con la mejor diligencia posible, sin garantía de disponibilidad continua. Pueden producirse interrupciones por mantenimiento o desconexión de la sesión que requieran un nuevo escaneo del código QR.

## 8. Resolución

Puedes eliminar tu sesión en cualquier momento desde tu panel de control. La plataforma se reserva el derecho de suspender una clave API en caso de incumplimiento de las presentes condiciones.
